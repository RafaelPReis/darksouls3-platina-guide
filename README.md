# 🔥 Dark Souls 3 - Guia da Platina & Cheat Sheet (Edição PT-BR)

[![Português](https://img.shields.io/badge/Idioma-Portugu%C3%AAs-green.svg)](README.md)
[![English](https://img.shields.io/badge/Language-English-blue.svg)](README.en.md)

Uma aplicação web moderna, responsiva e completa criada para ajudar jogadores a conquistarem a **Platina (100% dos troféus)** em **Dark Souls III** (incluindo todas as DLCs: *Ashes of Ariandel* e *The Ringed City*).

👉 **Projeto no GitHub**: [https://github.com/RafaelPReis/darksouls3-platina-guide](https://github.com/RafaelPReis/darksouls3-platina-guide)  

---

## ✨ Recursos & Funcionalidades

- 🇧🇷 **Localização 100% Oficial em PT-BR & Alternador de Idioma (PT / EN)**:
  - Todos os itens, feitiços, milagres, piromancias, anéis, gestos, infusões e chefes utilizam a tradução oficial em português do Brasil de Dark Souls 3.
  - Botão no topo para alternar instantaneamente entre **Português (PT-BR)** e **Inglês (EN)** sem perder o seu progresso!

- 🗺️ **Modo de Exibição por Área Única no Passo a Passo**:
  - Navegação fluida por área (*Cemitério das Cinzas, Santuário do Elo do Fogo, Muralha Alta de Lothric, etc.*).
  - Banners em destaque no estilo Fextralife com bordas duplas douradas e tipografia medieval.

- 👥 **Guia Completo das 26 Quests de NPCs**:
  - Acompanhamento detalhado das linhas de missões de todos os 26 NPCs do jogo com alertas de risco de falha.
  - Banners de aviso integrados diretamente nas áreas onde os NPCs aparecem.

- ⚔️ **Equipamentos Categorizados (34 Categorias)**:
  - 30 categorias organizadas para **Armas & Escudos** (Espadas Retas, Espadas Grandes, Ultra Espadas, Adagas, Katanas, Machados, Cajados, Escudos, etc.).
  - 4 categorias organizadas para **Armaduras** (Elmos, Peitorais, Manoplas e Perneiras).

- 📊 **Cálculo de Progresso em Tempo Real**:
  - Progresso geral e contadores individuais por área recalculados instantaneamente ao marcar qualquer caixa de seleção.
  - Salvamento automático do progresso no navegador via `localStorage`.

- 🔗 **Hiperlinks Externos em Nova Aba**:
  - Todos os links para a wiki abrem em uma nova aba (`target="_blank"`), garantindo que você nunca perca sua sessão no guia.

---

## 🛠️ Tecnologias Utilizadas

- **Frontend**: HTML5, CSS3 Vanilla (Tema Fextralife Dark Fantasy), JavaScript ES6+, jQuery, Bootstrap 3.
- **Armazenamento Local**: `jStorage` & `localStorage`.
- **Deploy**: Vercel / GitHub Pages.

---

## 🚀 Como Executar Localmente

1. Clone este repositório:
   ```bash
   git clone https://github.com/RafaelPReis/darksouls3-platina-guide.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd darksouls3-platina-guide
   ```

3. Abra o arquivo `index.html` no seu navegador ou rode um servidor local:
   ```bash
   node server.js
   ```
   Acesse no navegador: `http://localhost:8080/`
