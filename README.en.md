# 🔥 Dark Souls 3 - Platinum Guide & Cheat Sheet (PT-BR & English Edition)

A modern, responsive, feature-rich web application built to help players achieve the **Platinum Trophy (100% Achievements)** in **Dark Souls III** (including both DLCs: *Ashes of Ariandel* and *The Ringed City*).

👉 **GitHub Repository**: [https://github.com/RafaelPReis/darksouls3-platina-guide](https://github.com/RafaelPReis/darksouls3-platina-guide)  

---

## ✨ Key Features & Highlights

- 🇧🇷 🇺🇸 **100% Official PT-BR Localization & Instant English Switcher**:
  - Full game content localized using official Dark Souls 3 Portuguese (PT-BR) terms.
  - One-click top navigation toggle to switch between **Portuguese (PT-BR)** and **English (EN)** without losing your checklist progress!

- 🗺️ **Single Area Walkthrough View Mode**:
  - Clean area-by-area walkthrough display (*Cemetery of Ash, Firelink Shrine, High Wall of Lothric, etc.*).
  - Authentic Fextralife title banners featuring gold borders and Dark Souls typography.

- 👥 **Complete 26 NPC Quests Guide**:
  - Step-by-step questline tracking for all 26 NPCs with failure risk warnings and location banners.

- ⚔️ **Categorized Equipment System (34 Categories)**:
  - 30 categorized sections for **Weapons & Shields** (Straight Swords, Greatswords, Ultra Greatswords, Daggers, Katanas, Axes, Staves, Shields, etc.).
  - 4 categorized sections for **Armors** (Helms, Chests, Gauntlets, and Leggings).

- 📊 **Real-Time Progress Tracker**:
  - Real-time overall and area progress counter calculations on checkbox selection.
  - Automatic progress saving in browser `localStorage`.

- 🔗 **External Links in New Tab**:
  - All wiki links open in a new tab (`target="_blank"`), keeping your progress uninterrupted.

---

## 🛠️ Built With

- **Frontend**: HTML5, CSS3 Vanilla (Fextralife Dark Fantasy Theme), JavaScript ES6+, jQuery, Bootstrap 3.
- **Storage**: `jStorage` & `localStorage`.
- **Deployment**: Vercel / GitHub Pages.

---

## 🚀 How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/RafaelPReis/darksouls3-platina-guide.git
   ```

2. Navigate to the project directory:
   ```bash
   cd darksouls3-platina-guide
   ```

3. Open `index.html` in your browser or launch a local node server:
   ```bash
   node server.js
   ```
   Open your browser at `http://localhost:8080/`
